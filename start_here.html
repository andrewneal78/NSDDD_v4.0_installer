NSDDD 4.0: start here

Search 835 national security and defence documents from 125 countries by meaning, in English and in the original languages. It runs on your own computer; nothing you search for leaves it. This is a pre-release build: documents and figures may change before the public release.

A step-by-step user guide (PDF) covers the search settings, keyword and Boolean search, clusters, and using NSDDD with an AI assistant. It is also linked from the search page.

This is a pre-release version.
  • The full NSDDD 4.0 dataset will be released early in the new year. It will include all the new documents from 2026, plus other additions as they are found.
  • Until then, this pre-release is updated as bugs are found and fixed. Updates install themselves when you start NSDDD while online, and tell you when they have (see section 7).
  • Documents, figures and results may change between now and the full release, so please do not cite pre-release figures as final.
  • Tell the person who sent you this page if anything looks wrong. That is how the bugs get found.

2. Download and install (once)

Windows
  1. Open the download page and download NSDDD_4.0_Windows.zip (about 1 GB), for example into your Downloads folder.
  2. Unzip NSDDD_4.0_Windows.zip into a short folder on your main drive, for example C:\NSDDD. Avoid OneDrive, Desktop and long folder names.
  3. Double-click Setup.bat. If Windows says ‘Windows protected your PC’, click More info, then Run anyway.
  4. If it asks permission to install the Microsoft Visual C++ runtime, say yes. If your computer does not allow it, ask IT support to run runtime\vc_redist.x64.exe.
  5. Wait 10 to 20 minutes for ‘Setup complete’. Setup downloads the search data (about 2.5 GB), so it needs the internet; if the connection drops, run it again and it carries on where it stopped.
Mac
  1. Download the installer (a small zip file) and unzip it. Move the folder somewhere permanent, for example your home folder.
  2. Control-click Install NSDDD.command, choose Open, then Open again (only the first time).
  3. Leave the window open. It needs no Python of its own and takes 20 to 45 minutes, mostly downloading about 2.5 GB of data from GitHub. You need to be online.
  4. When it says ‘Done’, you can close it. Do not move the folder afterwards.

3. Start a search session

Windows: double-click Start NSDDD.bat. Use Start NSDDD Low Power.bat on a slow computer.
Mac: double-click Launch.command.
  • Your web browser opens the search page. It shows ‘Loading the search model’ for up to a minute, then the search form appears. If the browser does not open, go to http://127.0.0.1:8867 (the black window shows the address if it differs).
  • Keep the black window open while you work. Closing it stops NSDDD.
  • Once the form has appeared the model is ready, so every search takes only a few seconds. Keep to one browser tab: each extra tab loads its own copy of the model.

4. Your first search

  1. In the topics box, write one sentence the way a policy document would say it, for example ‘Armed forces support civil authorities during natural disasters.’ A sentence works better than a list of keywords or a question.
  2. Leave the other settings alone and press Search.
  3. Results are passages from the documents, best match first. Click the blue passage text to open the document at that place. For documents with an original-language version, the link opens original and English side by side.
  4. The results are grouped into numbered clusters, largest first. Hover over a cluster label to read the cluster’s most typical sentence.

5. Useful settings

Search thresholdDefault 0.72. Raise it to 0.75 when you need evidence (about 95% of passages at 0.75 or above are relevant). Lower it to 0.70 to explore; below 0.70 is mostly noise.
Cluster detailHigher means more, smaller clusters.
FiltersCountry, region, years, document type, and organisations such as NATO or the United Nations. Membership is counted as of the year each document was published, so a Finnish document from 2015 does not count as NATO. The Membership drop-down switches this to today’s members.
AI headingsOff by default. Press Add AI headings after a search to have a small model on your computer write a short heading for each cluster. Check each one against its example sentence.
ExportSaves an Excel file (default) to the outputs folder, with the settings and a normalisation sheet. Links in an export work only while NSDDD is running on the same computer.
Keyword searchTick it to find an exact word, including in other languages, for example Gesamtverteidigung.

6. Reading results carefully

  • Each passage is counted once. When both the original-language text and its English translation match, they are merged into one English result. A few original-language results can remain: these are passages whose English did not match. Untick ‘Count each passage once’ (under the language setting) if you want both counted.
  • Run three to five differently worded searches on a topic, not just one.
  • Not finding a topic in a country’s documents does not prove it is absent. Check which documents the country has in the dataset.
  • Long or numerous documents, such as Japan’s annual white papers, produce more hits. Use the normalisation sheet in the export before comparing countries.
  • Repeated sentences from yearly editions can form a cluster of their own.

7. Updates

New documents arrive the same way. When more documents are added to the pre-release, NSDDD downloads only the data files that changed (not the whole 2.5 GB again) and tells you when it has.

NSDDD is a pre-release and is improved as bugs are found. Each time you start it while you are online, it checks for a new version and installs it, then tells you in the black window and in a green box on the search page. If you are offline it simply starts the version you have. To check without starting a search, double-click Update NSDDD.bat (Windows) or Update NSDDD.command (Mac). Only the program files are replaced; your exports are not touched.

8. If something goes wrong

  • The page says it cannot connect: wait 30 seconds and refresh. Make sure the black window is still open.
  • A link shows ‘403’ or will not open: NSDDD must be running (black window open) on the computer that made the export. Package versions before 8 October 2026 also had a fault that blocked every link on Windows; use the latest package.
  • The computer is slow: close other programs, or use the Low Power start file (Windows).
  • Windows reports a missing DLL (VCRUNTIME140 or MSVCP140): run runtime\vc_redist.x64.exe, then Setup.bat again.
  • Setup stops with an error: send the file setup_log.txt (in the same folder) to the person who sent you the package. On a Mac, send a copy of the window.
  • To remove NSDDD: delete its folder.
